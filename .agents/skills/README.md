# Skills

Project-specific, reusable agent skills live here: one directory per skill,
each containing a `SKILL.md` (plus optional `scripts/`, `references/`,
`assets/` subdirectories), following the [Agent Skills
Specification](https://agentskills.io/specification).

Before adding a skill, see "About Skills" in AGENTS.md: it must be
project-specific, reusable, and have clear inputs/outputs/success criteria.
Files here are agent- and tool-agnostic.
